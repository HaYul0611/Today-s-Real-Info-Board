# 오늘의 진짜 정보판 — 데이터가 안 올 때 (Real Information Board)

> 매일 변하는 비개인 공개 원천의 실제 값을 매일 기록하고 어제와 비교하며, 데이터가 지연되거나 오지 않을 때도 직전 정상값을 보존하고 정직하게 설명하는 신뢰 정보판 대시보드입니다.

---

## 📌 프로젝트 소개

진짜 신뢰받는 데이터 제품은 값이 잘 들어올 때보다 **외부 원천이 지연되거나 장애가 났을 때** 결정됩니다.  
본 프로젝트는 외부 데이터 공급자의 오류나 네트워크 단절 상황에서도 화면이 깨지거나 빈 화면이 되지 않고, **마지막 정상값을 안전하게 유지(Stale State)**하면서 사용자에게 장애 상황과 권장 행동을 정직하게 안내하는 데이터 복원력을 구현했습니다.

---

## ✨ 핵심 기능 및 특징

### 1. 100% 실시간 비개인 공개 원천 연동 (비밀키 0건)
* **대한민국 기상청 모형 실시간 전국 기온**:
  * Open-Meteo 공개 API를 통해 전국 주요 14개 관측 앵커 및 50개 시·군의 실시간 지상 2m 기온, 체감온도, 습도, 풍속 관측
  * 24시간 실시간 시간대별 기온 변화 곡선 인터랙티브 차트 제공
* **글로벌 외환 실시간 현물 시장 (Spot FX) & 공식 고시 환율**:
  * 야후 파이낸스 실시간 현물환 시세 및 유럽중앙은행(ECB) 공식 고시 환율 연동
  * 주요 5대 통화(USD, EUR, JPY, GBP, CNY) 및 160개+ 전 세계 통화 실시간 원화 환산 계산기
  * 최근 7일간의 환율 변동 추이 꺾은선 차트 및 실시간 등락폭(▲/▼, %) 스파크라인 제공

### 2. 5대 장애 복원력 (Failure Resilience)
* **외부 5대 실패 상황 합성 시험**:
  1. **응답 지연 (Timeout)**: 1,500ms 제한시간 초과 시 정직한 원인 설명 및 [다시 시도] 안내
  2. **접근 거절 (401/403 Auth)**: 외부 공급자 인증 정책 거절 상황 안내
  3. **호출 제한 (429 Rate Limit)**: 60초 대기 권장 행동 가이드 제공
  4. **네트워크 단절 (Offline)**: 단말 오프라인 상태 감지
  5. **응답 형식 변경 (Schema Break)**: 스키마 파손 감지
* **마지막 정상값 불변 보존**: 어떤 실패가 발생해도 직전 정상 관측값이 절대 삭제되지 않으며 `오래된 값 (stale)` 배지 부여
* **원클릭 정상 복구**: `RECOVER-D2` 복구 실행 시 즉시 `fresh / none` 상태로 회복되며 익일 행 생성

### 3. 하루 한 줄 원자적 갱신 규칙
* `Asia/Seoul (KST)` 기준 `record_date`를 고유 식별키로 삼아 같은 날 여러 번 호출되어도 중복 없이 1건으로 원자적 갱신
* 다음 날짜 도래 시 신규 일별 행이 정확히 1건 추가 축적

### 4. 실제 이틀 기록과 어제 대비 변화값 엄격 재계산
* 서로 다른 2일간의 실제 기록(어제와 오늘)을 대조하여 `오늘값 - 어제값` 변화량을 수학적으로 엄격 재계산하여 표시
* 일별 기록 보관소 테이블에서 일자별 수치와 전일 대비 변화량 투명하게 확인

### 5. 3자 데이터 일치성 검증 (Tri-Inspector)
* 원천 API 응답 원자료(Raw JSON) = 내부 저장소 레코드(Normalized Record) = UI 화면 표시값(Screen Display)의 3자 일치성을 실시간 시각화

## 🛠 기술 스택

* **Frontend**: Vanilla HTML5, Vanilla CSS3 (Custom Glassmorphism & Financial Theme), ES Modules (JavaScript)
* **API**: Open-Meteo Weather API, Yahoo Finance Spot FX, Frankfurter ECB Exchange Rate API
* **No Framework / Zero Dependency**: 외부 무거운 프레임워크나 비밀키 없이 브라우저 시크릿 창에서 즉시 구동

### 로컬 환경에서 실행
```bash

git clone https://github.com/HaYul0611/Today-s-Real-Info-Board.git
cd Today-s-Real-Info-Board

# 로컬 웹 서버 실행 (정적 파일 서빙)
node test/serve.js
# 또는
npx serve .
```
